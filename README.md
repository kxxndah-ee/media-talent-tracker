# 📰 언론사 인사이동 & 이직 트래커 (Media Talent Tracker)

언론사 인사 기사를 자동으로 분석하여 **기자/간부의 경력 타임라인을 구축**하고, **타사 이직을 감지**하며, **동명이인을 필터링**하는 전용 트래킹 웹 애플리케이션입니다.  
PC와 모바일(스마트폰) 브라우저에서 편리하게 바로 열람할 수 있습니다.

---

## 🌟 주요 핵심 기능

### 1. 🔍 다차원 통합 검색 & 인물 상세 프로필
- **언론사, 부서, 직급, 성명** 다중 필터 및 통합 키워드 검색.
- 선택한 언론인의 **승진, 전보, 이직, 영입 이력을 시계열 타임라인**으로 시각화.
- 기사 원문 발령 문구 및 게재 일자 영구 보존.

### 2. 🚀 타사 이직 포착 레이더 (Transfer Radar)
- **직접 이직 감지**: 기사 내 `(전 OO일보 차장)` 또는 `[영입]` 등 이전 소속 명시 구문 자동 추출.
- **시계열 윈도우 + 직급 연속성 추적**:
  - A사 인사에 나타난 인물이 일정 기간(1~18개월) 내 B사 인사에 합당한 직급(수평 또는 승진)으로 등장할 경우,
  - 이직 확률 점수(신뢰도 지수 %)를 계산하여 **[이직 포착 레이더]**에 자동 등록.

### 3. 👥 동명이인 필터링 & 스마트 관리 (Homonym Disambiguation)
- **한자(漢字) 정밀 검증**: 한자가 일치하면 동일인 확정, 상이하면 100% 동명이인으로 분리.
- **직급 사다리 7단계 검증**: 시간 역전 또는 비현실적 직급 비약/강등 방지.
- **출입처/전문분야 일관성**: 정치/경제/사회/문화 등 전문분야 유사도 분석.
- **사용자 검증 (Human-in-the-Loop)**: 시스템이 감지한 동명이인 의심 케이스를 1-클릭으로 **[동일인 합치기]** 또는 **[동명이인 확정]** 가능.

### 4. 📝 인사 기사 실시간 분석 및 등록
- 포털이나 언론사 사이트의 인사 기사를 복사해서 붙여넣기만 하면 실시간 파싱.
- 미리보기 테이블 확인 후 클릭 한 번으로 DB 저장 및 프로필/이직 즉시 반영.

### 5. 📱 PC & 모바일 반응형 지원
- **모바일 완벽 지원**: 반응형 UI 적용. PC와 스마트폰이 동일 Wi-Fi에 연결되어 있으면 스마트폰 브라우저로 바로 접속 가능 (`http://<PC_IP>:8501`).
- 스마트폰 홈 화면에 '바로가기 추가' 시 독립형 전용 앱처럼 사용 가능.

## 🚀 빠른 시작 가이드

### 1. 실행 명령어
```powershell
# 프로젝트 폴더로 이동
cd C:\Users\user\.gemini\antigravity\scratch\media-talent-tracker

# 앱 실행 (간편 실행)
uv run streamlit run run.py
```

### 2. 접속
1. 브라우저가 자동으로 열립니다 (`http://localhost:8501`).
2. 별도의 로그인이나 비밀번호 입력 없이 대시보드가 즉시 실행됩니다.

### 3. 스마트폰(모바일)에서 접속하는 방법
1. PC와 스마트폰을 **동일한 Wi-Fi(공유기)**에 연결합니다.
2. PC에서 앱 실행 시 콘솔 또는 [설정] 탭에 표시되는 **Network IP**로 스마트폰 브라우저에서 접속합니다:
   ```text
   http://192.168.x.x:8501
   ```
3. 모바일 브라우저 메뉴에서 **[홈 화면에 추가]**를 누르면 스마트폰 앱 아이콘이 생성되어 터치 한 번으로 열립니다.

## 🧪 자동화 테스트 실행

```powershell
uv run python -m unittest discover -s tests
```
- `test_parser.py`: 인사 기사 불릿, 한자, 이전 소속 괄호 표기, 부서/직급 분리 테스트.
- `test_tracking.py`: 사내 승진, 타사 이직 감지, 한자 기반 동명이인 분리 테스트.
